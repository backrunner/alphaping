AlphaPing 面向个人、团队和小型组织。控制面运行在你自己的 Cloudflare 账户中，轻量 Rust Agent 安装在需要监控的机器上。

## 你可以做什么

- **监控机器**：查看 CPU、内存、磁盘、网络与运行时间，按需展开历史图表。
- **检查服务**：从 Cloudflare 执行 HTTP、TCP 检查，或通过 Agent 执行 HTTP、TCP、ICMP 探针。
- **查看容器**：在所属机器下查看容器状态与资源指标。
- **分享状态**：选择对外公开的机器和服务，发布 incident 与公告。
- **管理访问**：按工作区和资源分配查看、管理权限。

> AlphaPing 处于早期开发阶段。目前需要手动配置和部署控制面，生产 Agent 发布需要先完成签名与更新根配置。CI 构建产物适合评估，不等同于已配置的生产发行版。

## 两个组成部分

**Cloudflare 控制面**负责工作区、权限、历史查询、检查调度和公开页面。SvelteKit Web Worker 提供界面，独立 Worker 分别负责数据接收、实时连接、服务检查、通知和清理。

**Rust Agent**负责采集机器指标、执行探针、读取容器运行时，以及在本地暂存尚未确认上传的数据。机器身份由注册后的设备凭据确定，IP 地址只是资产信息。

## 开源与参与

AlphaPing 使用 Apache-2.0 许可证。你可以自托管、阅读和修改代码，按许可证要求分发。开发与贡献方式见[关于项目](/about)。
