## 选择公开范围

游客只能查看显式公开的 dashboard、状态页和资源投影。将资源加入公开页面前，先核对公开策略与资源级覆盖。

默认不会向游客公开机器 IP、Agent 版本细节、请求头、请求体、容器环境变量和内部错误堆栈。公开展示的是经过明确筛选的数据。

## 定制站点外观

管理员进入 **Admin → Appearance**，可配置：

- 站点标题与介绍。
- Iris、Ocean、Mint、Sunset、Rose 五套配色。
- 浅色或深色默认模式，以及舒适或紧凑密度。
- 导航 Logo 图片。

Logo 支持公开 HTTPS 地址或站内路径。透明图片按比例完整显示，加载失败时回退到 AlphaPing 默认标志。

访客可以在浏览器保存自己的主题偏好，并恢复站点默认。个人偏好不会写入数据库，也不会改变资源公开范围。

## 阅读状态时间线

每个胶囊代表固定时间桶，显示正常、降级、故障、维护或无数据。将鼠标悬停或用键盘聚焦，可以查看时间区间、可用率、延迟与失败摘要。

无数据不等于正常。展示的可用率和状态依赖实际检查结果。

## Incident 与公告

为事件设置受影响服务、严重级别、开始时间与当前状态，再按时间线追加进展。更新记录保留审计，不能静默覆盖历史。

公告支持开始与过期时间。公告到期后会立即从查询结果消失，后台稍后完成物理清理。计划维护会在状态时间线中单独表示。

## 自定义域名

可以将自定义域名直接指向公开 dashboard、机器或服务的根路径。域名路由通过 Web Worker 的 `DOMAIN_ROUTES_JSON` 配置；游客域名拒绝登录与管理路由。

配置格式和示例见[域名路由指南](https://github.com/BackRunner/alphaping/blob/main/docs/domain-routing.md)。
