## 日常监控

- [机器与容器](/docs/guides/machines)：阅读资源指标、机器状态和容器运行情况。
- [服务检查](/docs/guides/services)：选择 HTTP、TCP 或 ICMP，配置执行器和确认窗口。

## 分享与协作

- [公开状态页](/docs/guides/status-pages)：选择资源、定制外观、发布 incident 和公告。
- [权限管理](/docs/guides/permissions)：邀请成员，分配资源级查看与管理权限。

遇到问题时，先查看最后成功更新时间和检查执行器，再参考[排查问题](/docs/reference/troubleshooting)。
