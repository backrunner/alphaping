## 阅读机器列表

机器卡片展示设备身份、状态、CPU、内存、主要存储卷，以及上传、下载速率和累计流量。搜索与筛选条件保留在 URL 中，便于刷新和分享。

| 状态 | 含义                                     |
| ---- | ---------------------------------------- |
| 正常 | 在离线阈值内收到报告，指标未达到异常阈值 |
| 降级 | 机器仍在线，但资源或探针达到警告阈值     |
| 故障 | 仍可通信，但达到严重阈值或关键探针失败   |
| 离线 | 超过离线阈值未收到持久报告               |
| 维护 | 处于人工维护窗口                         |
| 未知 | 尚未成功上报，或现有数据不足以判断       |

状态同时通过文字与图标表达。未上报的机器会显示等待状态，缺失指标使用占位表示。

## 查看详情与历史

进入机器详情，先看当前指标、配置同步状态和最近事件。历史图表默认折叠，展开后才加载所选时间范围。

实时连接中断时，页面会标明最近更新时间并回退到持久数据。**实时连接中断不等于机器离线**：离线状态由持久报告和配置的离线阈值决定。

## 容器监控

容器属于机器的下级资源，不是单独的顶层模块。开启后，可查看 runtime、镜像、运行和健康状态、重启次数，以及可用的资源与端口摘要。

Agent 默认不读取容器环境变量、secret、挂载内容或日志正文。runtime 无法访问时会显示权限或连接错误，不会把它解释成“没有容器”。

系统服务与当前登录用户的运行环境不同。使用 Colima 或用户级 Docker socket 时，需要确认 Agent 服务账户的实际访问权限。

## 机器探针

在机器的探针任务中配置 ICMP、TCP 或 HTTP 任务，也可以指定另一台已接入的 Agent 作为执行器。配置按 revision 下发，页面需要同时关注期望 revision 与已应用 revision。

如何选择执行位置，见[服务检查](/docs/guides/services)。
