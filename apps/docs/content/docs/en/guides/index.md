## Everyday monitoring

- [Machines and containers](/docs/guides/machines): read resource metrics, machine state and container status.
- [Service checks](/docs/guides/services): choose HTTP, TCP or ICMP, an executor and confirmation windows.

## Sharing and collaboration

- [Public status pages](/docs/guides/status-pages): select resources, customize appearance and publish incidents and announcements.
- [Access control](/docs/guides/permissions): invite members and assign resource-level view and manage permissions.

When something goes wrong, check the last successful update and the selected executor first, then consult [Troubleshooting](/docs/reference/troubleshooting).
