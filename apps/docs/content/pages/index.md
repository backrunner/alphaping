AlphaPing 是开源的机器与服务监控平台。控制面部署在自己的 Cloudflare 账户中，Agent 支持 Linux、macOS 和 Windows。

从[部署控制面](/docs/start/deployment)开始，随后[安装 Agent](/docs/start/agent)、[添加服务检查](/docs/guides/services)，并[分享公开状态页](/docs/guides/status-pages)。
