AlphaPing is an open-source platform for monitoring machine resources and service availability. Deploy the control plane in your Cloudflare account and run Agents on Linux, macOS or Windows.

Start by [deploying the control plane](/docs/start/deployment), then [install an Agent](/docs/start/agent), [add service checks](/docs/guides/services) and [share a public status page](/docs/guides/status-pages).
