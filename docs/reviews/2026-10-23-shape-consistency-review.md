# AlphaPing 圆角与视觉一致性复核（2026-10-23）

本轮根据用户对大圆角和内容裁切的反馈，继续在已有依赖升级、响应式修复上调整。修改仅涉及设计规范、样式和 svedocs 主题配置；保留配色、品牌图形、触控尺寸、数据与权限行为。未提交、推送或部署。

## 统一规范

| 类型                   | 调整前                | 当前                  |
| ---------------------- | --------------------- | --------------------- |
| 输入、按钮、提示       | 12–14px，部分为胶囊   | 8px                   |
| 卡片、表格、小菜单     | 24px，部分页面自定义  | 12px                  |
| 面板、对话框、导航外壳 | 22–32px               | 16px                  |
| Hero                   | 桌面 36px / 手机 28px | 桌面 24px / 手机 20px |

控制台、公开站和文档站使用同一语义层级；移除普通表面写死的两位数圆角。状态标签、细进度条、轨道和 Logo 保留各自有意义的几何形状。设计文档明确本轮优先于历史的大圆角偏好。

## 具体问题与修复

- 大圆角与紧凑表格边距不匹配：缩小表面圆角，保持内容区和触控尺寸，不通过扩大裁切范围掩盖问题。
- 服务表最后一行悬停背景没有遵循底部圆角：为首尾背景设置扣除 1px 边框的内侧圆角；表格保留可见溢出，时间轴提示可以完整出现在表外。
- 手机机器/服务筛选栏的末尾选项藏在横向滚动区：采用可换行或三列布局，完整显示各状态，统一分段控件外壳与内层按钮的圆角。
- 文档搜索样式仍有不匹配当前 svedocs 组件的选择器：改为实际的 dialog/input/results 结构；输入框采用内侧焦点描边，搜索结果在手机端最多显示三行摘要，浮层高度按动态视口限制。
- 公开机器摘要栏的边缘链接可能裁掉外侧焦点描边：使用带独立小圆角的内侧焦点轮廓。
- 文档桌面表格外框铺满但表头和行内容缩在左侧：让最后一列吸收可用宽度，保持原生表格的列对齐与独立滚动；重新检查全部文档的六档宽度。
- 服务和权限分页的 Previous 被网格拉成整列宽度：统一为内容宽度，保留两侧按钮与中间页码对齐。
- 通知卡片移除悬停位移，与其他重复卡片保持一致的边框和阴影反馈。
