# AlphaPing 响应式 UI 审查（2026-10-23）

在本轮依赖升级和 SvelteKit 3 迁移的工作区上继续检查控制台、公开状态页与 svedocs 文档站。修复范围为布局、表单、导航、可访问性与浏览器交互；没有更改服务端权限、公开投影、数据库结构或遥测请求频率。本轮未提交、推送或部署。

## 浏览器验证

环境为本机 Edge、实际构建产物、临时 D1 和合成测试数据。使用 320、390、768、1024、1280、1440px 宽度；控制台 13 个页面、公开站 4 类页面和中英文文档 28 个页面分别覆盖浅色、深色。检查页面边界及主要布局容器的内部溢出，并对关键页面、弹层和交互状态查看实际截图。最终矩阵没有发现未处理的横向溢出；被测手机控制台可见按钮和表单控件满足 44px 高度。时间轴使用独立的 44px 控件，不强行放大每根柱的宽度。

- 控制台：总览、机器列表、服务列表、事件、资源创建、成员权限、公开与数据设置、外观、通知、审计、机器详情、服务详情、工作区选择。
- 公开页：总览、机器列表、机器详情、服务详情；检查外观菜单的窄屏布局、浅色模式和恢复默认选项的入口。
- 文档：28 个中英文页面，包含首页、文档、独立页面；检查双语切换、手机导航、Esc 关闭、搜索结果、代码复制反馈、回到顶部。
- 交互：机器筛选的选项展示和应用、搜索空结果、HTTP/TCP/ICMP 字段切换、响应断言添加、权限字段标签、机器配置/探针/事件标签页。
- 状态：无数据与空列表、离线机器、维护/未知服务、暂停通知渠道、超长渠道名、未公开资源的 404 页面、登录页、初始化环境与验证步骤。初始化其余步骤通过源代码审查和 Web E2E 验证。
- 历史：在浏览器临时模拟离线，确认错误文案与 Retry；恢复网络后重试，确认 Loading history 和真实的无历史数据状态。网络模拟已恢复。
- 键盘：手机抽屉 Tab / Shift+Tab 循环、Esc 关闭、焦点返回；时间轴方向键检查和 Esc 关闭提示。另测 390×390 短屏抽屉滚动。
- 通知测试数据只插入临时 D1，使用暂停渠道和禁用规则，不具备有效投递配置。
