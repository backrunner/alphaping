# AlphaPing 实际页面检查（2026-09-08）

本轮使用 Playwright 驱动真实 Chromium，打开本地 Cloudflare Worker 上的 production build，检查现有页面的视觉与交互。沿用工作区已有的界面改版，补充修复实际浏览发现的问题。

当前设计适合监控控制台：紧凑导航、等宽指标、明确的状态层级，机器使用重复资源卡片，服务使用可比较的行式布局。移动端保持指标密度，管理表格转为资源行，复杂配置逐层展开。整体不需要重新设计；本轮重点修正可读性、缺失数据表达和交互反馈。

## 已修复

| 问题                                                      | 改动                                                                                                             |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 表头等辅助文字在浅色/深色背景上对比度不足                 | 更新 `--text-faint` 为浅色 `#606973`、深色 `#929ba6`，同步自动/手动主题与设计文档。                              |
| 紧凑状态图标在普通 span 上使用不合法的 ARIA 标签          | 状态徽标使用带名称的 `img` 语义，保留文字、图标和颜色表达，不增加 live region。                                  |
| 容器内存说明破坏定义列表结构                              | 将容量说明放入对应的 `dd` 内，保持原有布局。                                                                     |
| 复制成功后切换平台、或后续复制失败，按钮仍可能显示 Copied | 平台切换与每次复制前重置反馈；异步完成时确认仍是同一条安装命令，避免旧操作更新新命令的提示。                     |
| 未上报机器显示 CPU 0%、内存 0 B                           | 机器卡片和详情以采样时间判断是否有数据，未上报时显示缺失值；卡片提示 Awaiting first report，真实零值仍正常显示。 |
| 默认错误页只有状态码和 Internal Error，没有恢复入口       | 加入与控制台一致的错误页，提供重试或返回入口；文案不输出内部异常，403/404 使用相同的不可用说明。                 |
| 文案不一致或暴露实现细节                                  | 主题控件统一为英文；首页说明改为监控用途；尚未检查的服务显示 Not checked yet。                                   |

这些改动没有增加轮询、历史预加载、D1 查询或写入，也没有增加运行时依赖。

## 浏览器验证

检查尺寸为 1440×900、1280×720、768×1024、390×844，每种尺寸分别检查浅色和深色主题。截图等待字体及布局动效稳定后采集。自动检查使用 axe 的 WCAG 2 A/AA、2.1 AA、2.2 AA 规则；自动结果不等同于完整的 WCAG 合规认证。

最终主页面矩阵覆盖 **15 个页面 × 4 种尺寸 × 2 个主题，共 120 组**。每组均确认 HTTP 200、有效页面标题及主内容，未发现页面横向溢出、JavaScript pageerror 或上述 axe 规则违规。覆盖首页、机器列表与详情、服务列表与详情、资源管理、权限、事件、公开访问设置、审计、通知，以及公开首页、机器列表、机器详情、服务详情。

容器页、配置页签、服务断言编辑器和安装命令另行展开复测，已修复问题均未再次出现。新增错误页分别以真实 404 路由和临时移除测试 D1 绑定产生的 500 检查，覆盖相同四种尺寸与明暗主题，共 16 组，均无溢出或 axe 违规；返回入口及重试按钮均通过实际点击验证。故障注入只修改 `/tmp` 下的预览配置。原始精简记录见 [browser-checks.json](assets/2026-09-08/browser-checks.json)。

主要命令为 `pnpm --filter @alphaping/web check`、`pnpm --filter @alphaping/web build`，以及 Web 目录下对 `src/lib/install-command.test.ts` 和 `src/theme-bootstrap.test.ts` 的 Vitest 检查。Playwright 与 axe 工具临时安装于 `/tmp`，没有加入产品依赖。

实际操作覆盖：移动导航打开、正反向焦点循环、Esc 关闭及焦点返回、跨桌面断点解除 inert；主题三种模式及刷新持久化；搜索的 URL 状态和无匹配结果；机器详情页签；历史折叠时不请求、展开后读取真实历史接口；服务断言编辑器添加与删除行；Agent 安装命令的平台切换、剪贴板实际内容和复制失败提示。

公开视图使用独立未登录浏览器检查。测试工作区的公开策略通过管理员表单设置；控制台仍重定向至登录页。检查了公开页面不包含测试机器的内部 hostname、预期主机地址、内部探测 URL、Agent 错误码及内部机器 ID。此检查仅覆盖所选测试字段，不代替完整权限和数据投影测试。

## 验证边界

本地预览期间，Wrangler 的开发代理曾退出，设置页也曾返回内部错误页面。首次自动记录只看 HTTP 状态，误将该错误页的 200 响应计入正常结果；后续检查加入页面标题与主内容验证，并重启预览重新检查，错误页不计为通过。

本轮浏览器检查使用小规模合成数据和 Chromium。未覆盖 Safari、Firefox、实体触摸设备、大量资源的视觉压力，以及真实 Agent 持续实时推流。实时地址为测试占位域名，因此验证了持久数据回退，没有宣称真实实时连接验收完成。完整 Web/D1 E2E 与各平台原生安装、服务重启和自动更新仍需独立完成，参见[上一轮审查](2026-09-07.md)。没有远端发布或部署，也没有终止其他项目的进程。
