# 文档首页 Retina 截图

原来的 1440 × 1120 有损 WebP 在桌面 Retina 屏幕上像素不足，细小文字也有压缩损失。现在从实际公开状态页组件和合成示例数据重新截图：浏览器视口为 1440 × 1120 CSS px，设备像素比为 2，原生输出 2880 × 2240 px。

明暗两套图片均提供无损 WebP，通过 `srcset` 和与首页布局匹配的 `sizes` 选择分辨率。保留图片宽高属性、主题切换和示例数据标注。截图用的临时预览路由已经删除。

| 资源                      | 像素尺寸    | 大小      |
| ------------------------- | ----------- | --------- |
| `dashboard-light.webp`    | 1440 × 1120 | 169,476 B |
| `dashboard-light@2x.webp` | 2880 × 2240 | 347,988 B |
| `dashboard-dark.webp`     | 1440 × 1120 | 198,682 B |
| `dashboard-dark@2x.webp`  | 2880 × 2240 | 341,312 B |

两个 2× WebP 解码后的像素均与浏览器原始 PNG 截图逐字节相同。1× 资源由原始 2× 截图缩小生成，没有放大旧图。

本次只修改文档首页图片及加载配置，不涉及依赖、数据库、Agent、Worker 热路径或权限。

## 浏览器验证

构建后的中英文首页分别验证浅色和深色主题，共 16 组检查，浏览器报错为 0。

| 视口宽度    | 设备像素比 | 图片显示宽度 | 实际加载像素宽度 |
| ----------- | ---------- | ------------ | ---------------- |
| 1440 CSS px | 1          | 1158 CSS px  | 1440 px          |
| 1440 CSS px | 2          | 1158 CSS px  | 2880 px          |
| 800 CSS px  | 2          | 758 CSS px   | 2880 px          |
| 390 CSS px  | 3          | 352 CSS px   | 1440 px          |

检查浏览器 `currentSrc` 和实际响应文件的解码尺寸，确认图片像素数足以覆盖显示宽度与设备像素比。主题切换保持相同图片高度，页面没有横向溢出；人工检查了明暗截图及 Retina 渲染结果。
