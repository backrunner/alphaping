## 验收边界

**当前不能声明整套发布验收通过。** 本机多次出现 `connect EADDRNOTAVAIL 127.0.0.1`，并伴随 D1 测试启动/执行超时。Node 24 和 26 均可复现；只读检查确认多个其他项目的孤立 workerd 实例占用了大量回环连接。本轮只清理了自己创建的 AlphaPing 测试进程，没有修改系统网络参数或终止其他项目的实例。

本轮未终止任何其他项目的进程。若需要跨项目清理，应先取得授权，并在执行前重新校验 PID、路径和父进程，防止 PID 被重用；机器相关进程明细不纳入公开报告。

完整 Web E2E、全部 D1 集成测试仍须在空闲开发机或 CI 完成。本轮浏览器自动化多次返回超时；后续已通过独立 Chromium 完成实际页面检查，修复及截图见 [2026-09-08 前端检查](2026-09-08-frontend.md)。Linux/Windows/macOS 的完整原生安装、重启、自更新矩阵也尚未运行。

## 性能与 Cloudflare 成本

首页历史查询最多返回 300 个桶。对 30/100/200 个可见服务，相比原来的 900/3000/6000 个桶，分别减少约 67%/90%/95% 的历史行传输；汇总仍从当前状态计算，故障服务仍优先显示。本改动不增加 Worker 请求、D1 写入、DO 存储或 R2 写入。回归测试以 501 个服务验证选择顺序、汇总边界和 300 行上限。

`cost:check` 的 30/100/150/200/300/1000 规模及容器、公共访问场景通过。模型仍显示大规模部署主要受 D1 写入、保留期、公开页面访问地域与缓存命中率影响，不能把小规模包含额度解释为所有规模免费。

本轮 30.2 秒 Agent 资源采样：最大 RSS **13.13 MiB**，平均 CPU **0.066%**。该样本来自本机短时、未开启容器监控的离线测试配置，只能说明该场景低于 30 MiB / 0.5% 门槛；不代表长期运行、32 个探测任务或大型容器环境的上限。最终加密依赖/构建参数调整后仍需在原生发布矩阵复测。

## 安装、升级与回滚

安装说明与平台前提见 [Agent 快速安装与兼容性](../../.agents/14-agent-installation.md)。首次安装的信任锚为部署者控制面的 HTTPS manifest 和页面给出的脚本 checksum；脚本不会自行执行 TUF 签名验证，后续自动更新使用已有签名链。

本轮没有 D1 业务 schema 或 wire protobuf 变更；Agent 本地 SQLite 增加 `probe_config.encrypted` 并迁移旧配置。**旧 Agent 无法直接读取迁移后的加密配置。** 升级前保留一致的身份/config/spool 备份，回滚使用支持该存储格式的修复版本。不能单独还原旧 transport sequence 或通过删除身份/spool 重装来绕过错误。

发布前仍需运行六个平台的原生产物构建、自检、服务安装/重启、签名更新与失败恢复；Linux 静态链接、macOS 11+ 和 Windows PowerShell 5.1/7 的兼容性声明以这些结果为准。
